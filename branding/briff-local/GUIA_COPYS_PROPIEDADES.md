# Copys de propiedades · ASESPRO Inmobiliaria

Criterio aprobado el 20/10/2026. Complementa el documento de marca para publicaciones de propiedades.

## Estilo

Texto claro, cercano, con voseo uruguayo y datos concretos. Apertura natural, características fáciles de recorrer y una sola invitación a consultar por privado. Evitar superlativos, urgencia inventada y frases genéricas como «oportunidad única» o «el hogar de tus sueños».

## Estructura del generador

1. Tipo de inmueble, operación y zona pública, si está confirmada.
2. Una frase breve sobre las características disponibles.
3. Características en líneas separadas, con emojis funcionales.
4. Servicios incluidos y situación de gastos comunes, solo si están confirmados.
5. Detalles públicos adicionales que aporte el usuario.
6. «📩 Escribinos por privado para conocer los detalles y coordinar una visita.»
7. ASESPRO Inmobiliaria e inmobiliaria.asespro.com.uy.
8. Pocos hashtags relacionados con marca, operación y tipo. La ubicación solo se agrega cuando esté indicada en la zona pública.

No publicar precio, calle, número de puerta ni unidad. No inferir baños, superficies, garantías, disponibilidad, estado ni servicios. Equipado no implica a estrenar ni totalmente equipado. Gastos comunes desconocidos se omiten; «Tiene gastos comunes» y «Gastos comunes incluidos» son condiciones diferentes. Los datos y el copy siempre se revisan antes de publicar.

La composición de las placas no impone la longitud del copy. El texto del pie puede ampliar los datos disponibles. El panel permite editarlo antes de exportar o enviarlo a la extensión; los cambios manuales se conservan hasta que se solicite actualizar el copy.

## OpenAI en el panel · 21/10/2026

En Propiedades, desplegar Configurar OpenAI, pegar la clave y Guardar clave. Se conserva cifrada con Windows DPAPI en `%LOCALAPPDATA%/ASESPRO Inmobiliaria/openai.dpapi`; no incluir ese archivo en el pack. Quitar clave elimina la copia local. No es necesario modificar ni recargar la extensión.

«Detectar con IA» envía a OpenAI únicamente el texto pegado. Quitá datos privados innecesarios antes de usarlo. «Generar copy con IA» usa los campos confirmados y el copy anterior como referencia para variar la redacción; no manda fotos ni videos. Se usa gpt-5-mini con Responses API, salida JSON estructurada y store=false. Cada generación consume la API de la cuenta; guardar la clave no realiza una llamada de pago ni verifica saldo.

Cada propuesta se puede revisar, aplicar, regenerar o descartar. Aplicar datos reemplaza los campos y vuelve a generar el copy local; después se puede solicitar el copy creativo. Aplicar copy no cambia los datos. Las ediciones durante una solicitud impiden aplicar una propuesta desactualizada. El generador local sigue disponible sin clave. No se publica automáticamente por generar o aplicar.

La IA puede equivocarse: la revisión humana de datos y copy sigue siendo necesaria. El servidor valida campos y rechaza algunos patrones de precio/dirección, pero no garantiza detectar toda información privada en texto libre.

Referencias de implementación: https://developers.openai.com/api/docs/guides/structured-outputs y https://developers.openai.com/api/docs/models/gpt-5-mini . Pendiente primera generación con una clave guardada por el usuario.


### Flujo simplificado

Solo se muestra Detectar con IA. Si falta clave o falla el proveedor, se presenta una propuesta con reglas locales y el aviso «IA no disponible. Se usó la detección normal», junto con el motivo. Los datos se revisan y se aplican con el mismo botón. Crear copy con IA es la acción principal de redacción; si falla, se presenta un copy de respaldo identificado sin IA. No se sobrescribe automáticamente el contenido actual.

La IA varía apertura, ritmo, estructura y llamada a la acción; puede conectar características confirmadas con beneficios cotidianos sin inventar hechos. Emojis pertinentes, voseo y párrafos breves. No se exige repetir una ficha o una frase inicial fija en cada inmueble.
